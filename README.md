## GPU服务器租用的收费由哪几项构成？

收费 = 显卡型号与显存 × 计费方式 × 配套资源（CPU、内存、云盘、带宽）× 使用时长，再叠加地域和合约折扣。只报“每小时 X 元”的报价，通常省略了后三项。

先看显卡。海外按需市场目前 RTX 3090 约 0.5 美元/小时，A100 0.68 美元/小时起，H100 1.33 美元/小时起，B200 2.71 美元/小时起。同一代卡显存不同，价格也不同，A100 40GB 和 80GB 是两个价位。

计费方式的影响同样直接。按量、包月、竞价、预留四种模式单价差别明显，腾讯云、阿里云这类大厂的 GPU 实例，按量计费通常比包月贵 30% 以上；竞价能再便宜一截，但不保证一直有货。

配套资源最容易被忽略。CPU 和内存要跟显卡匹配，64GB 和 128GB 内存的价差很直观；NVMe SSD 比普通 SSD 贵，训练时加载数据集的速度也差很多；带宽从 50M 升到 100M，每月可能多出几百到上千元。

地域和合约决定最后一段差价。香港节点延迟低、不需要备案，但带宽和电力成本高，单价比美国节点贵；国内节点对外提供网站服务需要 ICP 备案；年付比月付便宜，三年合约折扣更深。

## 按小时、包月、竞价、预留，四种计费方式分别怎么收费？

按量计费按实际使用时长结算，单价最高；包年包月提前承诺周期，月均价格最低；竞价实例用厂商闲置资源，价格最低但可能被回收；预留实例介于按量和包月之间，用承诺换折扣。

1. **按量计费**：以小时为结算单位，用多少算多少。适合短期测试、算法验证、突发任务。单价最高，长期满载跑下来账单会超过包月。部分平台关机后仍收云盘和 IP 费用，下单前要确认规则。
2. **包年包月**：提前付一个月、一年甚至三年，换更低的月均价格。适合业务稳定、负载持续的场景。腾讯云、阿里云的 GPU 实例一年合约通常比按量便宜 30% 以上，三年合约折扣更深。
3. **竞价实例**：价格最低，可能被系统回收。适合对中断不敏感的批处理，比如离线渲染、模型训练的某些阶段。Nebius 的 B300 按需价 9.50 美元/小时，竞价 0.99 美元/小时，差不多是十分之一，代价是随时可能被收回。
4. **预留实例**：承诺一段时间换折扣，灵活性比包月高。这类合约本质上是 take-or-pay：预留的小时数用不用都要付钱。CoreWeave 2026 年第二季度 98% 的收入来自这类合约，空闲风险落在客户这边。

判断标准很直接：日均使用超过 6–8 小时、连续跑几个月，包月更划算；只是偶尔跑几小时实验，按量更合适。算盈亏平衡点也简单：包月价 ÷ 按量小时价 = 每月需要跑满的小时数，低于这个数就按量。24 小时挂一个月是 720 小时，“每小时几块钱”乘出来并不便宜。

## 显卡之外，账单上还会出现哪些费用？

云硬盘、公网带宽或流量、IP、镜像授权、备份、高防，以及关机后仍在计费的存储和 IP。漏算任何一项，预算都会失准。

- **云硬盘**：系统盘和数据盘按容量和类型计费。1TB NVMe 和 240GB 普通 SSD 的成本差距不小，训练数据加载速度差别更大，按任务选。
- **带宽**：国内可选固定带宽包月或按流量计费；香港等境外节点带宽单价更高，50M 和 100M 每月差几百到上千元。传几十 GB 数据集前先估算流量，10M 带宽传输数小时的时间成本，往往超过带宽差价。
- **公网 IP**：标准配置一般含 1–3 个 IPv4，额外增加按月收费，有 IDC 报价 20 元/个/月。
- **关机计费**：按量实例关机后计算资源通常停收，云盘、IP、镜像继续计费。用完就释放，别只关机。
- **授权与防护**：Windows 授权（部分平台收取）、DDoS 高防、备份存储都可能单独计费；基础防护一般免费，大流量攻击防护要买套餐。

估算月成本可以用一个简单公式：按量小时价 × 每天使用小时数 × 30 + 云盘月费 + 带宽月费 + IP 月费。算出来的数字高于包月价，直接包月。

## 常见问题

**GPU服务器租用一个月大概多少钱？**

以公开活动价为例，入门档包月在 1500 元上下（阿里云 1503 元/月起），腾讯云当前有 175 元/7 天的短期活动；V100、A10 档更高；H100 按需 1.33–12.29 美元/小时，包月另算。不同配置之间不能直接比单价，先锁定卡型和显存。

**按小时和包月哪个便宜？**

日均使用超过 6–8 小时且连续数月，包月便宜；短期波动任务按量更灵活。按量单价通常比包月贵 30% 以上，满载运行很快超过包月。

**关机后还收费吗？**

计算资源通常停止计费，云硬盘、公网 IP、镜像等继续按小时或按月收费。具体规则看实例类型的计费说明，长期不用建议直接释放实例。

**竞价实例会被回收吗？**

会。竞价实例用闲置资源，厂商需要时收回，价格可以低到按需的十分之一（Nebius B300 竞价 0.99 美元/小时，按需 9.50 美元/小时）。适合能断点续跑的离线任务。

**国内租GPU服务器需要备案吗？**

绑定域名对外提供网站服务需要 ICP 备案；香港等境外地域不需要。纯训练、内网推理不涉及备案。

**一张显卡够跑大模型吗？**

看显存。24GB 显存能覆盖大多数中等规模模型；百亿参数级大模型微调，单卡显存不够，需要多卡或 A100/H100 级显卡。先确认模型能不能装进显存，再看算力。
